# LOOP SHAFT

LOOP SHAFT is a browser incremental mining game built around physical cause and effect: mine real nodes, move real loot, load the central elevator, and only convert finds after they reach Surface appraisal.

The project is developed milestone by milestone from `docs/game-design-requirements.md`.

## Development

```bash
npm install
npm run dev
```

Validation:

```bash
npm test
npm run build
```

Current development branch for Milestone 5 adds first Crew operations, multi-floor cargo routing, D-180 Ancient Ruins, run-local rare Equipment, and bounded offline progression while preserving the Phase 1–4 physical simulation path.
